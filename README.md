# LINE 訂餐 Bot 正式版

## 功能

- 傳送任何圖片：立即清空舊訂單並開始新一輪，不辨識圖片。
- 平常訊息不回覆。
- 一般點餐會累加，不會覆蓋前一次。
- 只有「改／換／改成／換成」才會覆蓋自己的舊訂單。
- 自動取得發言者自己的 LINE 顯示名稱；`@某人` 不會改變訂餐人。
- 支援 `統計`、`結單`、`我的訂單`、`清空`、`結束`。
- 訂單存入 SQLite。

## Render 環境變數

必填：

- `LINE_CHANNEL_SECRET`
- `LINE_CHANNEL_ACCESS_TOKEN`
- `GEMINI_API_KEY`

選填：

- `ADMIN_LINE_NAMES`：可執行「統計、結單、清空、結束」的 LINE 顯示名稱，以半形逗號分隔，例如 `ANITA,阿緯`。留空代表所有人均可。
- `GEMINI_MODEL`：預設 `gemini-2.5-flash`
- `DB_PATH`：預設 `data/orders.db`

## 使用方式

1. 在群組傳任何圖片，開始新一輪。
2. 大家直接輸入餐點。
3. 管理員輸入 `統計` 或 `結單`。

範例：

```text
豬腳飯 100
辣腿排飯 95
炒麻油雞飯 95
```

下一則：

```text
招牌飯90，雞腿飯105x2=210，鮭魚飯105，共405，謝謝
```

輸出：

```text
Wu Yi Ru :
豬腳飯 1
辣腿排飯 1
炒麻油雞飯 1
招牌飯 1
雞腿飯 2
鮭魚飯 1

----------------

豬腳飯 1
辣腿排飯 1
炒麻油雞飯 1
招牌飯 1
雞腿飯 2
鮭魚飯 1
```

## SQLite 注意事項

Render 未掛載 Persistent Disk 時，重新建立執行環境可能清除 SQLite 檔案。
如需長期保留，請掛載 Persistent Disk，並把 `DB_PATH` 設為例如：

```text
/var/data/orders.db
```

目前訂餐只需保留當輪資料時，即使不掛載也能正常使用。
