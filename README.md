# LINE 訂餐 Bot 正式版

## 功能

- 傳送任何圖片：立即清空舊訂單並開始新一輪，不辨識圖片。
- 平常訊息不回覆。
- 一般點餐會累加，不會覆蓋前一次。
- 只有「改／換／改成／換成」才會覆蓋自己的舊訂單。
- 自動取得發言者自己的 LINE 顯示名稱；`@某人` 不會改變訂餐人。
- 支援 `統計`、`結單`、`我的訂單`、`清空`、`結束`。
- 訂單存入 SQLite。

## Render 環境變數

必填：

- `LINE_CHANNEL_SECRET`
- `LINE_CHANNEL_ACCESS_TOKEN`
- `GEMINI_API_KEY`

選填：

- `GEMINI_MODEL`：預設 `gemini-2.5-flash`
- `DB_PATH`：預設 `data/orders.db`

## 使用方式

1. 在群組傳任何圖片，開始新一輪。
2. 大家直接輸入餐點。
3. 群組任何人輸入 `統計` 或 `結單`。

範例：

```text
豬腳飯 100
辣腿排飯 95
炒麻油雞飯 95
```

下一則：

```text
招牌飯90，雞腿飯105x2=210，鮭魚飯105，共405，謝謝
```

輸出：

```text
Wu Yi Ru :
豬腳飯 1
辣腿排飯 1
炒麻油雞飯 1
招牌飯 1
雞腿飯 2
鮭魚飯 1

----------------

豬腳飯 1
辣腿排飯 1
炒麻油雞飯 1
招牌飯 1
雞腿飯 2
鮭魚飯 1
```

## SQLite 注意事項

Render 未掛載 Persistent Disk 時，重新建立執行環境可能清除 SQLite 檔案。
如需長期保留，請掛載 Persistent Disk，並把 `DB_PATH` 設為例如：

```text
/var/data/orders.db
```

目前訂餐只需保留當輪資料時，即使不掛載也能正常使用。


## v1.2 更新

- 支援用 `+`、`＋`、`&`、`＆` 拆分多個餐點。
- 支援有空格的「和／跟」作為餐點分隔。
- 例如 `炒麵小+隔間肉湯=100謝謝` 會拆成：
  - 炒麵小 1
  - 隔間肉湯 1
- 例如 `炒麵 大 +荷包蛋` 會拆成：
  - 炒麵 大 1
  - 荷包蛋 1
- 個人訂單與總統計皆使用 A-Z／Unicode 排序。


## v1.3 更新

- `炒麵大`、`炒麵 大`、`炒麵　大` 會統一為 `炒麵 大`
- `雞腿飯加蛋`、`雞腿飯 加蛋` 會統一為 `雞腿飯 加蛋`
- 寫入資料庫前先正規化，因此統計會自動合併數量


## v1.4 更新

以下格式都會把 `x/X/×/*` 後面的數字視為數量：

- `炒麵大x3=150` → `炒麵 大 3`
- `綜合湯X3=180` → `綜合湯 3`
- `雞腿飯×2=210` → `雞腿飯 2`
- `滷蛋 * 4 = 60` → `滷蛋 4`

同時保留：

- `+`、`＋`、`&`、`＆` 拆分多個餐點
- 餐點名稱空格正規化
- A-Z／Unicode 排序
- 金額、總計、謝謝、Tag、Emoji 自動忽略


## v1.4.1 更新

- 取消管理員限制。
- 群組任何人都可以輸入 `統計` 或 `結單`。
- 群組任何人也可以使用 `清空`、`結束`。
- 不再需要 Render 環境變數 `ADMIN_LINE_NAMES`。
